# Urbana Mobilidade Elétrica · prévia para aprovação

Versão estática desta página, publicada para a cliente aprovar antes de ir ao ar
no domínio definitivo.

**Não é o site de produção.** Aqui não existe servidor: o formulário abre o
WhatsApp normalmente, mas nada é gravado e nenhum e-mail é disparado. A página
está marcada com `noindex` e tem `robots.txt` bloqueando tudo, para não ser
indexada e não competir depois com o site real.

Gerada por `publicar-preview.js`, a partir do repositório privado do projeto.
Não edite os arquivos daqui: eles são sobrescritos na próxima geração.
